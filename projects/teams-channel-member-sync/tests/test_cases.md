### A-3. 静的検査の回帰（実施済み）

「validate が全緑だった」は「自分が思いついた観点は通った」でしかない
（handbook/knowledge/lessons_learned.md §27）。そこで定義をわざと壊し、対応する検査が実際に発火することを確かめた。

| ID | 壊し方 | 発火する検査 |
|---|---|---|
| R01 | 括弧を1つ減らす | P02 式の構文 |
| R02 | 関数名の後の `(` を消す | P02 |
| R03 | メソッドを DELETE にする | P03 破壊的REST |
| R04 | URIに `deleteObject` を混ぜる | P03 |
| R05 | `X-HTTP-Method` を DELETE にする | P03 |
| R06 | 書き込みURIを `GetByTitle` にする | P04 リストIDで特定 |
| R07 | 想定していない REST を呼ぶ | P05 |
| R08 | `dataset` にサイトURLを直書き | P06 |
| R09 | ボディを文字列連結で作る | P07 |
| R10 | Graph 以外のホストを指す | P08 |
| R11 | チャネルIDの `uriComponent` を外す | P08 |
| R12 | 無効化をガードの外へ出す | P09 離脱ガード |
| R13 | ガード条件から件数チェックを外す | P09 |
| R14 | `threadType` を推測値（`Channel`）に変える | P10 |
| R15 | `body/recipient/channelId` を落とす | P10 |
| R16 | `Compose_AdminSiteUrl` に値を入れたまま出す | P11 |
| R17〜R19 | サイトURL・メール・GUIDの実値を混ぜる | P12 |
| R20 | 未初期化の変数を参照する | P13 |
| R21 | 存在しないアクションを参照する | P13 |
| R22 | Apply to each の並列オフを外す | P14 |
| R23 | `substring` から番兵を外す | P16 substring の空文字安全性 |
| R24 | 管理サイト未指定時の退避を消す | S05 手作業なしで動くこと |
| R25 | 管理サイト未設定を失敗として扱う | S05 |
| R26 | 次の操作の案内を消す | S06 |
| R27 | 既定ビューへの列追加を消す | P18 取得項目の表示 |
| R28 | ビューの作り直し（`removeAllViewFields`）を混ぜる | P18 |
| R29 | 設定リストを別サイトから引く | P17 設定リストの同一参照 |
