# インポート手順書

対象ZIP: `flows/create-initialized-list/release/CreateInitializedSharePointList_20260724211020.zip`

---

## 重要な注意事項（必読）

1. **本パッケージは実環境でのインポートと実行に成功しています（2026-07-24・`status: Created`）。** 新規作成から初期化完了までの主経路が通り、SharePoint 画面で「既定ビューが `sample_raw` の1列だけ」「不要な列が消えている」「`sample_raw` にHTML・リンクを保存できた」も確認済みです。
2. **ただし「同名リストが存在する場合」の経路は実機で発火していません。** このフローの最重要の安全機構がその経路にあります。**ステップ9（既存リスト名を指定して何も起きないことの確認）を必ず先に実施してください。**
3. **レガシー形式のパッケージです。** インポートは「パッケージのインポート **(レガシー)**」から行います。「ソリューションのインポート」ではありません。
4. **SharePoint接続は、インポート作業を行うご自身のアカウントのものを選び直す必要があります。** ZIPには認証情報は一切含まれていません。
5. **インポート後は必ず一度「保存」してください。** インポートが成功しても、保存で初めて検出されるエラーがあります。
6. **事前のSharePoint準備は不要です。** リストはフローが作成します。既存リストへの変更は一切行いません。

---

## 0. 事前準備

### 0-1. 権限の確認

フローを実行するアカウント（SharePoint接続に使うアカウント）が、対象サイトで次を行えることが前提です。

- サイトを参照できる
- リストを作成できる
- 列を作成・削除できる
- ビューを変更できる
- （ロールバックを機能させる場合）リストを削除できる

権限が不足している場合は、結果JSONで `ERR_PERMISSION_DENIED` として区別されます（URL不正や同名リスト存在として扱いません）。

### 0-2. 入力値の用意

| 入力 | 例 |
|---|---|
| SharePointサイトまたはリスト一覧URL | `https://{tenant}.sharepoint.com/sites/{site}` または `.../_layouts/15/viewlsts.aspx` |
| 作成するリスト名 | `SampleList`（日本語・空白を含む名前も可） |
| リストの説明（任意） | 省略時は「Power Automateにより作成された初期化済みリスト」 |

URLは SharePoint の画面からコピーしたものをそのまま貼り付けてください。対応する形式は [url_parsing_spec.md](url_parsing_spec.md) §1 を参照してください。

## 1. Power Automate を開く

1. ブラウザで `https://make.powerautomate.com` を開きます。
2. 組織アカウントでサインインします。
3. 画面右上の環境名を確認し、フローを作りたい環境が選ばれていることを確認します。

## 2. 「マイフロー」→「インポート」→「パッケージのインポート (レガシー)」

1. 左側メニューの「マイフロー」をクリックします。
2. 上部の「インポート」ボタンをクリックします。
3. **「パッケージのインポート (レガシー)」** を選びます。

> 「ソリューションのインポート」ではありません。メニューの文言はテナントのバージョンによって多少異なります（「レガシーのインポート」等）。

## 3. ZIPをアップロードする

1. 「アップロード」欄をクリックし、対象のZIPを選びます。
2. アップロードが完了すると、フロー名「SharePointリスト新規作成＋初期化（既存リスト保護）」（論理名 `CreateInitializedSharePointList`）と、必要な接続が表示されます。

## 4. 「新規作成として」に設定する

1. フロー名の右側の操作列をクリックします。
2. **「新規作成として (Create as new)」** を選びます。
3. 既存フローへの上書き（更新）は選ばないでください。

## 5. SharePoint接続を選択する（接続参照の設定手順）

パッケージが必要とする接続は **SharePoint 1本だけ**です。

1. 「関連リソース」または「接続」の一覧に「SharePoint への接続を選択してください」という行が表示されます。
2. 行をクリックし、ドロップダウンからご自身の既存の SharePoint 接続を選びます。
3. 使える接続が無い場合は「新規作成」（＋アイコン）をクリックし、サインイン画面でご自身のアカウントで認証します。
4. 接続が正しく選択されると、行の左側にチェックマークが表示されます。

> **接続の中身について**: ZIP内では接続情報は匿名化されており（`connectionsMap.json` の値は実在しないGUID）、インポート時にここで選んだ実接続へ再マッピングされます。ZIPに認証情報は含まれていません。
>
> この再マッピング挙動は、**本フロー自身が 2026-07-24 に実環境でインポート・実行に成功したことで SharePoint コネクタでも実証されています**（`handbook/rules/07_export_import_package_rules.md`）。

## 6. インポートを実行する

1. すべての接続行にチェックマークが付いていることを確認します。
2. 画面下部の「インポート」をクリックします。
3. 完了メッセージが出るまで待ちます。

## 7. フローを開いて「すぐに保存」する（省略不可）

**この手順は省略しないでください。** インポート成功は保存できることを意味しません。

1. 「マイフロー」に戻り、追加されたフローをクリックします。
2. 「編集」をクリックしてデザイナーを開きます。
3. **何も変更せずに** 右上の「保存」をクリックします。
4. 保存に成功したら次へ進みます。

> 配布状態のパッケージは 2026-07-24 に実環境で保存・実行できています。デザイナーで手を加えた後に保存が失敗した場合は [troubleshooting.md](troubleshooting.md) §3 を参照してください。
>
> **設定変更は不要です。** 本フローには環境固有の値（サイトURL・リスト名など）を保持している変数がありません。すべて実行時の入力から導出されます。したがってインポート後に書き換えるべき変数はありません。

## 8. フローチェッカーを実行する

1. デザイナー右上の「フローチェッカー」をクリックします。
2. 「エラー」「警告」タブの内容を確認します。

## 9. まず「同名リストが既に存在する」ケースで安全性を確認する（推奨）

**いきなり新規作成を試さず、まず既存リストを指定して「何も起きない」ことを確認してください。**

1. デザイナー右上の「テスト」→「手動」→「テスト」をクリックします。
2. 入力します。
   - SharePointサイトまたはリスト一覧URL: 対象サイトのURL
   - 作成するリスト名: **そのサイトに既に存在するリストの名前**
   - リストの説明: 空欄
3. 「実行」をクリックします。

期待される結果:

| 確認箇所 | 期待値 |
|---|---|
| `Compose_Flow_Output` の `status` | `AlreadyExists` |
| `Compose_Flow_Output` の `success` | `true` |
| `Scope_Create_List` 内の `Create_Generic_List` | **スキップ**（実行されていない） |
| `Scope_Initialize_List` 以降の各スコープ | 中の処理がすべてスキップ |
| 指定した既存リスト | SharePoint 画面で開き、**列・ビューが変わっていないこと** |

**既存リストが1文字も変わっていないことを目視で確認してください。** これがこのフローの最重要の安全確認です。

## 10. 新規作成を確認する

1. 再度「テスト」→「手動」を開きます。
2. 入力します。
   - 作成するリスト名: **そのサイトに存在しない新しい名前**（例 `SampleList_test01`）
3. 「実行」をクリックします。

期待される結果:

| 確認箇所 | 期待値 |
|---|---|
| `Compose_Flow_Output` の `status` | `Created` |
| `list.itemCount` | `0` |
| `initialization.sampleRawCreated` | `true` |
| `initialization.defaultViewFields` | `["sample_raw"]` |
| `initialization.deletedFields` | 削除できた列の一覧 |
| `initialization.skippedSystemFields` | `CanBeDeleted=false` の列（Title 等） |

SharePoint 画面で作成されたリストを開き、次を確認してください。

- 既定ビューに表示されているデータ列が `sample_raw` だけであること
- `sample_raw` にHTML（`<a href="https://example.com">リンク</a>` 等）を保存でき、リンクとして機能すること
- リスト設定で添付ファイルが無効になっていること

## 11. 段階的に確認する

1. 既存リスト名 → `AlreadyExists`（何も変わらない）
2. 大文字・小文字だけ違う既存リスト名 → `AlreadyExists`
3. 新しい名前 → `Created`
4. 3で作った名前をもう一度 → `AlreadyExists`（2回目は作られない）
5. 不正な名前（`Sample/List`）→ `ERR_LIST_NAME_INVALID_CHARS`

各段階で**既存リストが変更されていないこと**を確認してください。

## 再インポート（更新）について

`release/` 内の既存ZIPは上書きされません。ビルドし直した場合は新しい日時付きファイルが追加されるため、**最新のタイムスタンプのZIP**を使ってください。
