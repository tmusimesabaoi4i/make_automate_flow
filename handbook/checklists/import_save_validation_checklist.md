# インポート・保存検証チェックリスト

ZIPパッケージの作成前後・インポート前後に機械的/操作的に確認する項目。
詳細は[../templates/package_validation_report_template.txt](../templates/package_validation_report_template.txt)を参照。関連ルール: [../rules/07_export_import_package_rules.md](../rules/07_export_import_package_rules.md)

## §A source検証（ZIP生成前）
- [ ] **`python tools/wdl_lint.py --all .` を実行し、指摘0件であることを確認した**（案件横断の共通リンター。L01〜L13＋Markdownの M01/M02）
- [ ] **その案件の validate_*.py が `tools/wdl_lint.py` を import している**ことを確認した（汎用検査を案件ごとに手書きしない。手書きすると同じ穴が再生産される）
      → 全フローの充足状況は `python tools/doc_audit.py` の **C07** で機械確認できる（2026-08-04 に全7フローへ適用済み）
- [ ] **REST URI を実証済みの `definition.json` から逐語コピーした**（handbook の要約から書き起こしていない。要約は索引であって正典ではない）
- [ ] **ドキュメントに載せた REST 断片も同じ規則で検査した**（文書に残った誤った形は次の実装にコピーされる）
- [ ] validate_*.py（validate_definition.py/validate_list_definition.py等）を実行し、エラー・警告とも0件（全緑）であることを確認した
- [ ] tools/gen_outline.pyで生成したアウトラインが、想定したアクション構成と一致することを確認した（既存フロー修正時は変更前アウトラインとの差分も意図どおりであることを確認した）
- [ ] 匿名化漏れ（実メールアドレス・実GUID・実サイトURL等の実値）および参照元フロー固有のトークンが0件であることを確認した

## §B パッケージ作成後（機械検証）
- [ ] ZIPを再展開できることを確認した
- [ ] パッケージ内の全JSONファイルがパース可能であることを確認した
- [ ] （レガシー形式以外を扱う場合のみ）XMLファイルがパース可能であることを確認した。レガシーパッケージはXMLを含まないため該当なし
- [ ] connectionReferencesのキーと、apisMap.json/connectionsMap.json/manifest.jsonのリソースGUIDが一致していることを確認した
- [ ] 全アクションのrunAfter参照先が、同一コンテナ内の兄弟アクションとして実在することを確認した
- [ ] パッケージ内のフロー数が想定通り（子フロー・複数親フローの有無）であることを確認した
- [ ] 全アクション名（表示名）がフロー全体で重複していないことを確認した
- [ ] 実値ID・URL・メールアドレス・接続GUID等の機密情報が混入していないことを確認した（匿名化漏れがない）

## §C 環境準備（インポート前）
- [ ] インポート先環境に対象コネクタ（SharePoint等）の接続が実在することを確認した
- [ ] 対象サイト・リストが存在することを確認した（消費側フローの場合、リスト作成フローの実行が済んでいるか確認した）
- [ ] インポートを実行する担当者が対象サイト・リストへの必要権限を持っていることを確認した
- [ ] DryRun等のテスト実行の対象期間・件数を計画したか確認した

## §D インポート後（Power Automate画面上の操作）
- [ ] インポートを実行し、エラーが出ないことを確認した
- [ ] フローを開き、すべてのコネクタの接続を実環境の接続に再選択した
- [ ] SharePoint等のサイト・リスト・ライブラリを実物に再選択した
- [ ] 再選択後、そのまま一度保存し、保存エラーが出ないことを確認した
- [ ] フローチェッカーを実行し、警告・エラーが0件であることを確認した
- [ ] 小期間（1件または1日分程度）でテスト実行し、期待通りの結果になることを確認した
